Found by devbin-vc and kovacs-sysadm on kovacs, 31 Oct 2026. hv ruled on 1 Nov, in devbin-vc's window, that a Molt session fixes it.

As found. Molt-matts' config/zsh/zprofile runs brew shellenv, prepends MacGPG2 and ~/.local/bin, and adds ~/.cargo/bin last, after the system's directories. kovacs has rustup (stable-aarch64-unknown-linux-gnu, its cargo and rustc symlinks to ~/.cargo/bin/rustup) and Homebrew's rust 1.99.1, which Utilz's formula brings in. `whence -ap cargo` lists Linuxbrew's cargo first, so rustup's toolchain, and any rust-toolchain.toml a project adds, are bypassed. The two are the same build today, and only their version lines differ ("(Homebrew)"). Once they diverge, a cargo build on kovacs follows brew's cargo rather than the project's pin, and so does Devbin's ST0011 WP16 cache key, which asks cargo its version where the workspace is.

rhadamanth and gyges have no rustup, so cargo and rustc there are Homebrew's alone, and ~/.cargo/bin holds only tools cargo installed: cargo-audit, cargo-tauri and mdq on rhadamanth, none of them also on PATH; cargo-tauri, mdbook, mdq and rg on gyges, where rg (ripgrep 13.0.0, a 2023 leftover) would outrank Homebrew's 15.2.0 if ~/.cargo/bin moved ahead. Molt-flynn (Flynn's Mac, jormungandr) still builds PATH in zshrc, after Homebrew's directories: the shape Molt-matts left on 24 and 30 Oct (issue 0076). A non-interactive shell there gets neither ~/.local/bin nor ~/.cargo/bin, and it still exports INTENT_HOME and UTILZ_HOME, which Molt-matts retired as harmful.

hv's rulings, 1 Nov, in molt-vc's TUI: use rustup. ~/.cargo/bin goes ahead of Homebrew's bin wherever rustup is installed, so kovacs takes the new order now, and rhadamanth and gyges get rustup later, on a quieter day and booked, with no further config change. Every Molt-* config is fixed: Molt-flynn takes Molt-matts' PATH block, without its two exports. gyges-sysadm removes gyges's stale ~/.cargo/bin/rg. molt-dc builds, vc reviews, proves and merges, and hv pushes. 0078 stays held.

Fix. In Molt-matts' zprofile, straight after brew shellenv and before the MacGPG2 and ~/.local/bin prepends, prepend ~/.cargo/bin when ~/.cargo/bin/rustup is executable; anywhere else it stays last, so a Homebrew release outranks a stale cargo-installed copy. ~/.local/bin stays first, as the env liberator requires (lib/env.sh). zshrc's PATH comments and instances/kovacs/agents/sysadm.md:38 change with it. Molt-flynn takes the same PATH block: built whole in zprofile, path_prepend, and zshenv's fallback for a non-login shell.
