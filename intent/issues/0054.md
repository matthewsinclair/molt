When the manifest enables no liberator for this platform, molt_enabled_liberators prints nothing. resleeve (lib/molt.sh, "No manifest found, using all available liberators") then falls back to liberator_list and runs every liberator Molt ships. upgrade and maintain do the same. That includes keys' sudo build of keyd on Linux, and agents.

The same fallback serves a sleeve with no manifest at all. A manifest that exists but enables nothing for the platform may mean "run nothing", not "run everything".

Question for hv: should a manifest that is found but enables nothing for this platform be refused by name, or run nothing, instead of running every liberator? templates/molt.toml.example documents the current behaviour (70f1d98). Nothing is built until hv rules.
