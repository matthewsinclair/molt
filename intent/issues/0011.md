The iTerm2 ssh wrapper that the zsh liberator generates (`_zsh_generate_iterm2_ssh_colors` in `liberators/zsh.sh`, rendered to `~/.config/molt/iterm2-ssh-colors.sh`) reset the tab colour after `command ssh` and returned the reset's status. A failed ssh (255) therefore reported 0 to whatever ran it: a script's `ssh host cmd || ...` never took its failure branch.

Fix: keep ssh's `$?` across the reset and return it. Pinned in `test/liberators/zsh.bats`; checked under zsh as well.

Not in this fix: the reset colour is `000000`, while rhadamanth's base profile is `#15191F` (see wip.md).
