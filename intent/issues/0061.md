## What happened (kovacs, 25 Oct 2026; Molt release-candidate Linux check at d15b82d, run by kovacs-sysadm)

Every one of agents.bats' 30 failures on kovacs prints `install: cannot remove '/etc/apparmor.d/bwrap-userns-restrict': Operation not permitted`, then `agents: sandbox profile: sudo could not install /etc/apparmor.d/bwrap-userns-restrict`. The tests' sandbox-profile step aims at the host's real `/etc/apparmor.d`, through sudo. It failed on kovacs only because the test's sudo did not get root. kovacs-sysadm checked afterwards: the real profile and its `.molt-orig` and `.molt-rendered` copies are unchanged (mtime 2026-10-22T16:24:02), and journald holds no sudo entries in the window.

The cause: `molt_apparmor_dir` (lib/molt.sh) echoes `/etc/apparmor.d` with no override, and `lib/agent.sh` builds the installed profile's path from it. The managed-settings floor is redirected into the test root, but the AppArmor profile is not. On a Linux host where sudo needs no password, a test run overwrites the host's profile and `molt_apparmor_load` loads it into the kernel (`sudo apparmor_parser -r`). It passes on macOS because the sandbox-profile step is Linux only.

## Spec (vc, 25 Oct 2026)

- `molt_apparmor_dir` takes its directory from one override variable, the same way the managed-settings floor's root does, defaulting to `/etc/apparmor.d`. That one function stays the only place the path is named.
- test_helper points the override at the test root for every test, before any file's own setup runs, as it does for the agents root.
- No test reaches the real sudo or the real `apparmor_parser`. test_helper puts stubs first on PATH that record their argv and do nothing, the same as the launchctl stub from 0059. A test that exercises sudo or the parser fakes its own in front.
- A tripwire: a test run on Linux leaves `/etc/apparmor.d` unchanged. It is asserted from outside the suite, in the judge, by comparing mtimes before and after. It is not a test that touches /etc.
- Each new test is red with the change reverted. The full suite runs under Homebrew bash and /bin/bash, and on kovacs through kovacs-sysadm, with agents.bats green.
