`cmd_resleeve` (bin/molt:111-117) looks only at its first argument, and only for `--dry-run`. Any other argument is ignored, and a real resleeve runs. So `molt resleeve --help`, `molt resleeve -h` and a typo for a dry run such as `molt resleeve --dryrun` each resleeve the machine. `cmd_upgrade` (lib/molt.sh:2746) and `cmd_maintain` (lib/molt.sh:2886) already refuse with `Unknown option: <arg>` and return 1. resleeve is the one command that writes without that refusal.

Seen on rhadamanth on 27 Oct, at 06:37Z by date -u. molt-vc ran `molt resleeve --help 2>&1 | head -15` to read its usage, and a real resleeve started. `head` closed the pipe after fifteen lines, and the run died partway through the zsh liberator. It had re-rendered `~/.config/starship.toml` with its `.molt-rendered` sidecar (checked whole: the sidecar's output digest matches the file, and the powerline lines all came through) and regenerated `~/.config/molt/iterm2-ssh-colors.sh`. Nothing else changed. The harm was small because rhadamanth's config dir had already moved. On a sleeve armed for the move, the same slip could start the move, or refuse it partway through a run nobody asked for.

Fix: parse resleeve's arguments the way upgrade and maintain do. Loop over them, take `--dry-run`, and refuse anything else, flag or word, with `Unknown option: <arg>` and exit 1 before anything is read or written. Tests: `molt resleeve --help`, `-h` and `--dryrun` each exit 1, name the argument, and leave the sandboxed HOME unchanged. `molt resleeve --dry-run` still previews.


## As built (dc, 30 Oct 2026; merged by vc at 495b968)

- `bin/molt`: `cmd_resleeve` reads every argument before anything else is read: `--dry-run` sets a dry run, and anything else, flag or word, is refused with `Unknown option: <arg>` and status 1.
- `liberators/editors.sh`: the ImageMagick rebuild advice ends in a plain `molt resleeve`, since resleeve takes no liberator's name.
- Tests (`test/molt.bats`): `--help`, `-h`, `--dryrun`, the word `now`, and `--help` after `--dry-run` each exit 1, name the argument, and leave the sandboxed HOME's listing unchanged; `--dry-run` still previews (a guard). The five refusals failed before the fix, under bash 5.3 and /bin/bash 3.2.
