# ST0007: molt agent start: launch a sleeve agent by its role

## Objective

Start a sleeve agent with one command. `molt agent start <role>` runs Claude Code in the agent's home as `claude start --name <host>-<role>`, the word `start` its first prompt, after the checks a launch by hand skips. `molt agent roles` lists the roles this sleeve declares, `molt agent home <role>` prints a home, and `molt agent config` takes a role as well as a name. Every agent's contract says what it does when its first prompt is `start`.

## Context

hv, 23 Oct 2026, after rhadamanth's move (ST0006). Every sleeve agent is launched by hand, as `cd $MOLT_AGT_DIR/<host>-<role> && claude start --name <host>-<role>`: ST0006 gave each agent a home and a guard, but no launcher, and never said what an agent does first, so one launched without a first prompt waits for one (kovacs-sysadm and geodica-estate, 23 Oct; vc todo 20). `claude start` is not a Claude Code subcommand, and 2.1.309 has none of that name: it opens an interactive session whose first prompt is the word `start`.

hv's spec:

```
# Start an agent on this host as <role>, ie:
#   cd $MOLT_AGT_DIR/<host>-<role> && claude start --name "<host>-<role>"
molt agent start <role>

# List all roles configured in molt for this host
molt agent roles [list|...]

# ... and so on.
```

The spec named the root `MOLT_AGENT_HOME`; Molt's agents root is `MOLT_AGT_DIR`, and stays the one variable. vc builds this on head, since only vc is working (hv: fail and fix forward).

The checks `start` makes before it hands over, each refusing with the fix and starting nothing:

- the role is declared on this sleeve, and those that are get listed when it is not; and it is enabled;
- its home is current, else `molt resleeve`;
- on a sleeve that declares a config dir, this shell's `CLAUDE_CONFIG_DIR` is that dir, compared as the home guard compares it, since the guard would refuse the session's first prompt anyway;
- no Claude Code session of that name is running;
- `claude` is on PATH.

Arguments after `--` go to `claude` as they are.
